# Project Overview

## Client
QualFM - Facilities Management Company

## Project Goal
Build a modern, professional website for QualFM that positions them as a leading facilities management provider. The site should be clean, crisp, glassmorphic, and follow current web standards.

## Scope

### In Scope
- Responsive website (mobile-first)
- Home page with hero, services, sectors, CTAs
- About Us page
- Services pages (main + individual service pages)
- Sectors/Industries page
- Contact page (glassmorphic modal - completed)
- Demo content for all sections
- Glass morphism design system

### Out of Scope
- Backend/CMS integration
- Contact form submission handling
- Blog/News functionality
- Careers portal

## Current Focus (Updated February 21, 2026)

- Owner Portal completion (full control and reporting)
- Client Admin Portal restriction and polish
- Worklist-based execution and client reporting from admin tools
- Customer portal automation remains on backlog only

## Brand Guidelines

### Colors
| Color | Hex | Usage |
|-------|-----|-------|
| Navy Blue | `#2B2D5F` | Headers, primary text, key UI elements |
| Forest Green | `#3D7C3F` | Accents, CTAs, highlighting |
| Light Gray | `#C8C8C8` | Backgrounds, dividers, secondary text |
| White | `#FFFFFF` | Backgrounds, cards, breathing room |

### Design Principles
- Mobile-first approach
- Glassmorphic UI elements
- Clean typography
- Strong visual hierarchy
- Smooth animations
- Accessible design

## Technical Stack
- React 18 + TypeScript
- Vite (build tool)
- CSS with custom glass morphism utilities
- Deployed on Vercel

Project started: January 2026
